ZERO-TO-FUTURE — STARTER WEBSITE
================================

WHAT'S INCLUDED
- index.html: home page
- articles/: 3 starter article drafts
- about.html, contact.html, privacy.html, terms.html, disclosure.html
- styles.css: site styling
- pinterest_content_plan.csv: first 14 Pin ideas

IMPORTANT BEFORE PUBLISHING
1. These are starter drafts, not a finished researched affiliate site. Edit and add original value, examples, and your own visuals.
2. Replace the contact placeholder with a real contact method.
3. Review privacy/terms pages for the services you actually use; these are not legal advice.
4. Do not add Amazon affiliate links until accepted into the Associates Program.
5. After approval, use Amazon's current disclosure requirements. The required statement is included as a reminder in the template; remove or adjust it if you are not yet an Associate.
6. Verify product dimensions, specifications, prices, and availability directly before making recommendations.
7. Do not copy retailer product images or other creators' Pinterest images without permission/licensing.
8. This is a static website. It can be hosted using GitHub Pages from a public repository for free, but updates require uploading/editing files in GitHub.

SUGGESTED FIRST ACTION
Open index.html in your browser to preview the site locally. Then create a new public GitHub repository named zero-to-future and upload all files while preserving the articles folder. Enable GitHub Pages in repository Settings > Pages. Do not use your existing Ayesha Web Studio repository; keep this project separate.
